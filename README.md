### ★ v2.0.1 — 海马层 SDM 就近存储化 (串扰根治)

真实测试暴露海马"短回复被长回复污染" (尾部串扰 + 长度错位 145 vs 102)。
根因: 旧海马是线性外积叠加 E += outer(ev, ctx), recall = E@query =
Σ_e ev_e × (ctx_e·query) — 所有历史事件的输出信号全部混入, 正是
experiment29 证明失败的方案。按"假说-诊断-修正"流程重构:

1. 首版 SDM (k=128, 稀疏二值地址) 实测失败: 高 k 强制地址共享 → 超长位置
   块被长事件填充 → 所有回忆长度塌向 317 → 停止信号失效。
2. 诊断: margin 分布 (有内容 med 521 vs 无内容 med 40) 可分; 稀疏二值
   地址重叠计数离散 0/1 → top-k 并列随机化。
3. 修正: **低 k 地址专用** — 小库 (20 事件) 应每事件独占地址槽而非共享:
   - 连续 ±1 固定投影地址 (无并列歧义), n_addrs=4096, k=4
   - 冲突期望 k²/N×C(E,2)≈0.74 对 → 几乎零跨事件污染
   - 输入/输出正交块分区 (in 96 块 + out 320 块, v14.2 教训迁移)
   - 停止信号: 块 raw 信号阈值判停 (nul_thr=25, 实测 20/20 最优)
   - 长回复支持: max_pos_out=320 (原 256, 覆盖 317 字节最长回复)

改进前后 (真实测试): [7] 海马 2/5 → **5/5**; [8] 多轮 1/3 → **3/3**;
20 对长回复独立验证 0/20 → **20/20**。红线合规: 学习 = Hebbian 共发放
就近叠加; 地址 = 固定随机投影; 解码 = 位型内积 argmax。

### ★ v2.1 — 泛化通路 (MSP 统计层 + 原型兜底 + LIF 慢变量)

调研驱动的开放对话泛化升级。v2.0.1 真实测试确认: 新输入 5 轮全乱码 —
海马无记忆 → LIF 无快照漂移。根因: 系统是**纯记忆检索**, 缺"从统计结构
到生成"的通路。生物线索 (Schapiro 2017 海马双通路; Kanerva SDM 原型
构造; Subramoney 2024 神经元慢变量) 映射为三项机制 (候选 1+2+3, 用户选定):

```
                    海马 SDM 双通路 (v2.1)
  用户输入 ──→ bind(输入) ─┬→ _active(k=4)   → content[TSP 情景]  精确检索
                           └→ _active(k=128) → stats[MSP 统计]    统计学习
  回忆: content 有命中 → 精确补全 (原路径, 零回归)
        无命中 (开放新输入) → 原型 = stats均值/cnt → 块内 argmax
        = 同主题事件统计平均 (多数投票/原型构造 → 泛化生成)
```

1. **MSP 统计通路** (`SDMEventMemory.stats`, k_stats=128): 大 k 刻意共享
   地址槽, 从同主题事件提取共同统计结构 (Schapiro 2017 单突触通路;
   TSP 小 k 保留事件特异性, MSP 大 k 统计共享 — 同一固定投影, 红线内)。
2. **原型兜底** (`_recall_prototype`, proto_fallback=True): 具体事件无命中
   (输出区无任何块信号 ≥ nul_thr) → 退化为 `stats/cnt` 统计原型生成,
   直击"海马无记忆 → LIF 无快照漂移 → 乱码"根因。空库返回 NUL (安全)。
3. **LIF 慢变量** (SFA, Opt-in 默认关): 发放后阈值偏移升高 (频率适应),
   每步按 sfa_decay 缓慢衰减 — 慢变量跨字符持续, 把"最近发放历史"留在
   神经元状态里, 对抗 LIF 无快照状态漂移 (Subramoney 2024)。已确认放宽
   红线 (阈值偏移是神经元固有动力学, 非突触修改)。chat.py `--sfa-inc` 开启。

   ★ **训练/推理一致性 (质量关键)**: 无 SFA 模型推理开 SFA → 位置头输入
   分布失配 → 全乱码 (实测)。必须在训练时同步开启 (`train.py --sfa-inc 0.05`,
   train_full 所有阶段共用), 推理用同参 (chat.py 加载模型自动沿用
   sim.sfa_inc=0.05)。SFA 参数精密敏感: 实测 0.05 峰值, 0.03/0.1 骤降。

真实测试 (test_v2_1.py / test_v2_1_zh.py):

| 验证点 | 结果 | 说明 |
|--------|------|------|
| [1] 库内精确回忆 | **5/5** | 统计层不干扰 TSP 检索 (零回归) |
| [2] 原型兜底 (英文) | "Good afternoon!" → **'Good morning! How are you?'** | 同主题未见变体 → 统计原型生成; 原型关 → 空串 |
| [3] 空库安全 | OK | 无事件 → NUL, 不崩不产生垃圾 |
| [4] LIF 慢变量 | OK | thr_shift 累积 118, 状态活跃 155→99, 256/256 位差异 |
| [5] 结构提取 | OK | 未见变体 → 'The weather today is clony..' (共享前缀保留, 尾部统计混合) |
| [7]/[8] 中文回归 | **5/5, 3/3** | v2.0.1 基线零回归 (中文 2 字节编码全链路) |
| SFA 一致性 (candy_zh_sfa) | 快照复述 **16/20**, 首字符 **18/20** | 训练 sfa_inc=0.05 + 推理同参; 不一致 (推理 0) → 0/20、12/20 |

已知残余: 原型生成是统计平均, 事件稀疏处有字符级噪声 ('clony'/'iou' 类
混合); 原型只对"主题聚集"的库有效, 单一孤立事件无法构造结构。
端到端实测 (candy_zh_v21, hidden256): 主题聚集库 (英文问好 5 事件) →
未见变体 'Good afternoon!' 生成 'Good morning! How are you?' (合理泛化);
但分散主题库 (中文知识问答 5 事件) 原型 = 跨主题混合 ('历史出语中送给的
学家对蛋岁'), 因 MSP 大 k 混入不同主题事件; SFA 开/关端到端输出不同
(动力学生效) 但对未学内容 LIF 仍乱码 (慢变量不能创造未学结构)。

### ★ v2.2 — 从条件反射到内部思考 (预期门控 + 组合重放 + 好奇采样)

诊断: v2.1 系统本质是**刺激→联想→反应**闭式链路 (Pavlovian 条件反射) —
库内复述 16/20、首字符 18/20 都是"查表式联想", 库外新输入全乱码; 缺三个
"内部思考"要素: ① 自发生成 (无输入时内部活动) ② 预测 (前向模型) ③ 误差
驱动 (预测 vs 实际)。文献调研 (Saponati & Vinck 2023 预测学习规则;
Bakermans 2025 组合式重放; Spens & Burgess 2024 生成式记忆构建; Stoianov
2022 生成式重放; novelty encoding 新异性编码) 映射为三项 Opt-in 机制
(用户选定 A+B+C):

```
                    v2.2 三大机制 (从条件反射 → 内部思考)
  A 预期门控 Hebbian (训练期学习规则升级)
     预期信号 = W_coact·state (共激活回忆, 非学习) → gate = (recall > θ)
     Δw = lr × RPE × pre × gate — 只强化"被预期活跃"的突触
     = Saponati 预测学习规则: 放大最能预测其他输入的突触 (预测性 Hebbian)
     ★ 仅改学习规则, 不改变编码动力学 → 无训练/推理一致性约束 (≠ SFA)
  B 组合式离线重放 (睡眠期"想象", offline_replay.combinatorial_replay)
     抽两事件 (in1,out1)(in2,out2) → split 切分 → new_out = out1[:s]+out2[s:]
     以 in1 为线索重放训练 → 学 A-B, C-D → 泛化出 A-(B₁+C₂) 组合
     = Bakermans 组合式重放: 离线组合基元 → 无新学习泛化
  C 好奇驱动采样 (chat.py --curiosity, 选择性记忆)
     novelty = 1 − content 通路命中度 (输出区最大块信号 / k×char_ones)
     novelty ≥ 阈值 (默认 0.5) → 写入海马 (意外/库外 = 高价值)
     熟悉输入 → 跳过重复写入 (novelty encoding, 冷启动空库 = 1.0 全写入)
```

文献依据:
1. **Saponati & Vinck, Nat Commun 2023**: 预测学习规则 — 神经元在膜电位
   中学输入动力学低秩模型, 放大"最能预测其他输入"的突触, 复现 STDP
   时序不对称; 单神经元局部信息, 仍属 Hebbian 家族 (红线内)。
2. **Bakermans et al., Nat Neurosci 2025**: 组合式重放 — 离线组合基元 →
   无新学习泛化; **Spens & Burgess, Nat Hum Behav 2024**: 回忆 = 主动
   重建而非检索副本; Stoianov 2022: 层级生成模型离线重放虚构序列。
3. **novelty encoding**: 海马/腹侧被盖区对新异刺激的编码 — 系统只把
   无法从现有记忆重建的输入写入记忆 (选择性记忆, 高价值优先)。

v2.2 测试 (test_v2_2.py, 全部通过):

| 验证点 | 结果 | 说明 |
|--------|------|------|
| [A1] 向后兼容 | **逐位相同** | expected_gate=0 ↔ 无门控 (gate=None), W_ctx_to_first 完全相同 |
| [A2] 门控生效 | max\|ΔW\|>0 | expected_gate=0.5 改变学习 (与无门控权重不同) |
| [A3] 门有判别性 | 部分开放 | W_coact 累积后 θ=0.5 开 ~60%; 早期弱 (预测能力是习得的); θ=0 恒全开 |
| [A4] W_seq 门控 | 跑通 | train_sequence(expected_gate) 不报错 |
| [B] 组合重放 | 泛化成功 | 学 'Hi there!'+'I am fine.' → 重放后 in1 生成 'Hi m fine.' (后半 71% 匹配 out2 结构) |
| [B4] 函数级 | 2 组合/单事件 0 | combinatorial_replay 跑通, 事件不足安全返回 |
| [C] 新异性 | 库内 0.0 / 库外 1.0 / 空库 1.0 | content 命中度判据 (nul_thr 成熟阈值量级分离), 区分完美 |

真实训练对比 (test_v2_2_live.py, hidden 256/3 层, 种子 42, 14 英文对话):

| 配置 | W_seq best_acc | 库内复述 | 说明 |
|------|------|------|------|
| gate=0 (基线) | 9.9% | **14/14** | 位置头完全学会 (快照链路) |
| gate=0.5 (预期门控) | 9.9% | **13/14** | 基本持平 (微降 1, 记忆能力不破坏) |

★ 实测定位: 预期门控是**学习规则升级** (只强化被预期活跃的突触), 不是
记忆性能魔法 — 库内复述 14→13 持平 (LIF 位置头已知对初始化敏感, 1 项
波动属噪声区间)。其价值在预测性学习 (Saponati): 弱配置下同样生效
(max|ΔW|=0.45, 门开 62/96), 为未来"自发预期"通路打基础。

设计要点 (红线合规):
- A 的预期信号是**固定联想矩阵 W_coact 的线性回忆** (非学习), 门是布尔
  {0,1} — 不产生连续数值学习信号; 学习规则仍为 Δw = lr × RPE × pre。
- B 的拼接是**离散字符操作** (虚构经验的自洽奖赏); 学习仍为 RPE 调制
  Hebbian。红色约束: 组合重放只拼接"共享结构"回复, 不做逐字混搭检索。
- C 的 novelty 是**纯联想打分** (固定投影 + 块信号求和), 无梯度; 判据
  复用 v2.1 成熟阈值 (有内容块信号 32 vs 无内容 ≈6, 量级分离)。

### ★ v2.3 — 边学边用 (在线持续学习: 位置头在线扩展)

问题: v2.2 系统的"持续学习"是记忆累积型 (海马增删查), 不是权重进化型
(新皮层突触更新) — `train_on_dialogue` 存在但不更新位置头 (已知限制),
LIF 推理期权重冻结, chat.py 默认不调用在线学习。

方案 3 (用户选定): **位置头在线扩展** — 绕过"位置头不随在线学习更新"
限制:

```
★ v2.3 在线持续学习 (chat.py --online, 位置头自动扩展)
  每轮对话生成后:
    sim.train_on_dialogue(inp, chosen)   # 自洽奖赏 (生成回复做 RPE)
  train_on_dialogue(train_pos=True) 内部:
    1) W_ctx_to_first 增量更新 (原有)
    2) ★ 位置头在线扩展: 对回复每个位置 k
       - k ≥ len(W_ctx_to_pos) → 自动 append 新位置头 (uniform 初始化)
       - 每个头用 (acc_state + _mem_feature + RPE Hebbian) 训练 n_iter 次
       → 新学对话也能被位置头修正 (与 train_pos_heads 同机制, 无 coord)
    3) W_seq 增量更新 (原有)
```

真实测试 (test_v2_3.py, 500 条语料在线学习, candy_zh_v22 起训):

| 阶段 | 结果 |
|------|------|
| [基线] 学习前 | 新对话全 miss (乱码) — 位置头只训练过原 20 对 |
| [增长] 位置头 | 256 → **395** 自动扩展 (机制工作 ✓) |
| [边用] 每 100 条抽样 | 全部 miss — 共享位置头容量饱和 |
| [复述] 学习后 | **0/10**, 输出退化为"混合模板" (灾难性遗忘) |

★ 关键发现 (2026-08-05 实测, 持续学习的架构边界):
- **机制建立成功**: train_on_dialogue 位置头自动 append 工作 (256→395),
  chat.py --online 链路完整。
- **共享位置头容量饱和**: 每个位置头被所有对话共享更新 → 500 条轮流
  覆盖 → 输出退化为混合模板 (如"建议与咖啡相关的符号…" = 多个翻译/
  文案对话模式的统计平均)。这是**持续学习的灾难性遗忘** (新覆盖旧 +
  模式平均化), 不是参数问题。
- **状态漂移**: 在线学习无快照 (500 条快照 ≈ 500MB 内存不可行),
  W_coact 连续累积 → 训练/测试状态不一致, 进一步加剧 miss。
- **边界结论**: 共享位置头架构只支持小规模增量 (几十条内); **大规模
  持续学习的主力仍是海马** (20/20 精确复述, store→recall 即时可用)。
  位置头在线扩展适用于"少量新知识的生成质量微调"。

机制要点:
- **自洽奖赏**: chat.py 用生成回复做 RPE 目标 (无外部答案时的持续学习);
  test_v2_3.py 用语料真值做 RPE (教师信号, 验证位置头机制本身)。
- **无 coord 一致性**: 位置头在线扩展与 train_pos_heads 同款编码 (无
  context_coord), 生成测试同链路 (v2.1 一致性教训)。
- **红线合规**: Δw = lr × RPE × pre (RPE ∈ {−1,0,+1}); 位置头 append 是
  离散结构增长 (非连续数值信号); 无梯度/BP。

### ★ 多次运行波动 (真实测试发现, 已修复)

  的脆弱性仍在 ([6] 11-12/20 波动), 但海马通道 (v2.0.1) 已接管主链路,

## 项目目标

构建一个**纯粹的生物神经元计算系统**，目标是实现**类脑思考**而非大语言模型式的统计预测。

### 核心原则

- **不走 LLM 路线**：不使用 Transformer、Attention、Embedding、Tokenization 等大语言模型技术
- **不用求导**：任何形式的导数、偏导、梯度计算都不允许
- **不用梯度反向传播**：完全禁止反向传播算法、自动微分 (autograd)、梯度下降及其变体
- **不用损失函数**：不使用均方误差、交叉熵等任何形式的误差函数
- **不用批量优化**：每个样本独立学习，不累积梯度，不批量更新

### 生物学第一性原理

神经科学的已知事实决定架构设计，而非工程便利：

| 生物学事实 | 架构实现 |
|-----------|---------|
| 神经元膜电位是连续值 | V ∈ [0, 1] 膜电位积分 |
| 神经元发放是"全或无" | 二值输出 {0, 1} |
| 突触连接是稀疏的 | 选择性连接掩码 (~50% 稀疏) |
| 抑制性中间神经元实现 WTA | 侧抑制机制 |
| STDP 是局部的、奖赏调制的 | 奖赏调制 Hebbian 学习 |
| 工作记忆通过持续发放维持 | 0-1 分级状态累积 + 随机遗忘 |
| 神经元不会连接到所有其他神经元 | 选择性连接，非全连接 |
| 学习不需要标签，只需要结果好坏 | 二值奖赏信号 (+1/-1) |

## 架构概览

### 四层隐藏层 + 双记忆层结构 (v13)

```
输入层 (256 维)  ──→  L1 (256)  ──→  L2 (256)  ──→  L3 (256)  ──→  L4 (256)
                     │              │              │              │
                     └── 选择性连接掩码 (50% 稀疏)  层间权重 W_deep (v12 渐进式训练)
                     └── 侧抑制 (WTA) 每层内部
                                                                    │
                                        ┌───────────────────────────┤
                                        ▼                           ▼
                              工作记忆层 MemWork           关联记忆层 W_coact
                              (v12.2 now 模式:           (共发放追踪 + 回忆提取,
                               max(V累积, recall))         v12.3 确定性快照)
                                        │                           │
                                        └─────────────┬─────────────┘
                                                      ▼
                                  位置记忆头 W_ctx_to_pos[k] (v13, 修正非首字)
                                                      ▼
                                              输出解码 (W_ctx_to_first / W_seq / W_h2o)
```

- **L1 权重 (W_ih)**: 随机固定输入权重，永不训练
- **L2-L4 层间权重 (W_deep)**: **v12 渐进式深度训练** — 逐阶段加深 (输入→L1→输出 →
  输入→L1→L2→输出 → ... → L1..L4)，新层初始化为恒等映射 (纯中继)，保持已学表示不被破坏
- **工作记忆层 MemWork**: v12.2 now 模式 — `max(V 累积膜电位, recall)`，无跨字符累积；
  v12.4 recall 改为**分级回忆强度**（非二值化，判别性修复关键）
- **关联记忆层 W_coact**: 共发放追踪 + 回忆提取；v12.3 确定性快照保证训练/评估状态逐位一致

### 组件清单

| 组件 | 维度 | 说明 |
|------|------|------|
| W_ih | 1024×1024 | 随机固定输入权重 (L1)，带 50% 选择性连接掩码，永不训练 |
| W_deep | 3×1024×1024 | L1→L2→L3→L4 层间权重，奖赏调制 Hebbian 训练 |
| V / V_deep | 1024×4 | 各层膜电位向量，每个神经元 ∈ [0, 1] |
| W_h2o | 8×1024 | 解码权重，奖赏调制 Hebbian 训练 |
| W_ctx_to_first | 8×1024 | 记忆状态→首字符，奖赏调制 Hebbian 训练 |
| W_ctx_to_pos[k] | 8×1024 × 61 | **位置记忆头 (v13)**: 记忆状态→回复第 k 字符，生成时修正非首字 |
| W_seq | 8×1024 | 记忆状态→下一字符，奖赏调制 Hebbian 训练 |
| W_coact | 1024×1024 | 关联记忆层，共发放追踪 + 回忆 |
| MemWork | 1024 | 工作记忆层，0-1 分级上下文状态 |

## 核心机制

### 0-1 膜电位神经元

```
漏电:     V = V × (1 - leak)
积分:     V = clamp(V + sum(W_ih × input), 0, 1)
发放:     output = 1 if V > threshold else 0
重置:     V = V × (1 - reset_factor) if fired
侧抑制:   未发放神经元的 V 被抑制
```

### 纯二值奖赏调制 Hebbian 学习（唯一允许的学习规则）

```
Δw_ji = lr × dopamine_j × out_j × pre_activity_i

dopamine_j = +1 (该位正确), -1 (该位错误)
out_j      = 突触后神经元二值输出 {0, 1}
pre_i      = 突触前神经元二值活动 {0, 1}
```

**这是整个系统中唯一允许的权重更新方式。** 没有梯度、没有反向传播、没有自动微分、没有损失函数。

### 字符编码

```mermaid
flowchart LR
    A[字符 'H'] --> B[ASCII 码 72]
    B --> C[RandomState(72)]
    C --> D[256 维二值向量\n~50% 活跃]
    D --> E[+ input_bias=1.0]
    E --> F[输入信号 {1, 2}]
```

### 工作记忆层 (v12.2 now 模式 + v12.4 分级回忆)

```python
# 工作记忆 MemWork — "now 模式", 无跨字符累积 (v11 移除 forget_mask / OR 累积)
v_peak = V_deep[-1]              # 最深层累积膜电位 (V 跨字符持续累积, 不 reset)
recall = recall_from_memassoc(L4_out)  # 分级回忆强度 (W_coact 提取, v12.4)
MemWork = max(v_peak, recall)    # 逐元素最大, 不跨字符 OR 累积
```
**已验证的顺序约束** (experiment9 / diag_cmp3)：`update_coactivation` 必须先于
`recall`；`v_peak` 必须取累积 V (而非输出)；不逐字符 reset。任何顺序/来源变更
→ 状态判别性崩塌 (0-2/14 vs 9-11/14)。

**v12.4 关键修复 — 回忆由二值化改为分级** (diag_ctx_discrim):
- 原: `recall = (raw > 0.5).float()` — 阈值二值化丢失回忆强度信息，
  经 max 注入状态后判别性崩塌 (独立 W_ctx_to_first 5/14)
- 现: `recall = clamp(raw / (H/2), 0, 1)` — 先除期望最大共激活数再饱和钳位，
  保留分布形状 → 14/14
- ★ 反例: 直接 `clamp(raw, 0, 1)` 也失败 (4-5/14) — raw 量级常 > 1，
  直接钳位大量饱和，信息同样丢失

### 关联记忆层 (v10 + v12.3 快照)

```python
# 关联记忆 W_coact: 共发放追踪 (Fire together, wire together)
# 学习: 每个字符处理时累积共发放 (归一化到 [0,1])
# 回忆: recall = clamp(W_coact × L4_out / (H/2), 0, 1)   # 分级回忆强度 (v12.4)
# 注意: 这是突触矩阵线性回忆 (Hebbian 回忆)，不是余弦相似度/向量检索
#
# v12.3 确定性快照 — 连续累积是判别性来源, 但评估时必须重放训练时的状态:
#   收集: 每个对话编码前记录 W_coact.clone() → _coact_snapshots
#   评估: 恢复对应快照 + update_memory=True 重放 → 与训练状态逐位一致
#   W_seq: 同样方案 (train_sequence 逐对话记录 _seq_snapshots)
#   反例: 单一冻结 → 状态余弦 1.000 崩塌; 评估继续累积 → 状态漂移 (2/14)
```

### 层间渐进式深度训练 (v12)

```python
# W_deep (L1→L2→L3→L4): 逐阶段加深的课程式学习
# 阶段 depth=1..4:
#   1. 若 depth>1: 新中间层初始化为恒等映射 (scale=1.0, noise=0.0) — 纯中继
#   2. 训练 W_h2o (RPE 解码) + 李层 (仅当 mean_rpe>0: ΔW=lr×mean_rpe×outer(后,前))
# 恒等初始化保证: 新层加入前表示已正确, 无错误 → 无 RPE → 不更新 → 不被破坏
# 生物学依据: 皮层分层逐级成熟; 全局多巴胺奖赏门控 (只强化不惩罚)
```

### 循环生成 + 位置记忆头修正 (v13)

```mermaid
flowchart LR
    A[上下文状态 MemWork] --> B[W_ctx_to_first]
    B --> C[首字符]
    C --> D[编码→四层前向 L1→L4]
    D --> E[关联记忆更新/回忆 + MemWork 累积]
    E --> F[W_seq]
    F --> G[下一字符候选]
    G --> H{位置记忆头 W_ctx_to_pos[step]<br/>记忆优先覆盖 (θ=0)}
    H --> I[最终下一字符]
    I --> D
```

**位置记忆头 (v13)** — 对非首字结果进行修正:
- 训练: `train_pos_heads(dialogues)` — 对回复每个位置 k 训练独立 Hebbian
  分类器 W_ctx_to_pos[k] (上下文状态 → 第 k 字符, 与 W_ctx_to_first 同机制)
- 修正: 生成时每步用位置头对上下文状态 cf 回忆"回复第 step 字符"并直接
  覆盖 W_seq 候选 (记忆优先); 超出已训练位置回退 W_seq
- **快照一致性**: train_pos_heads 必须复用 `_coact_snapshots` 恢复状态再
  编码, 否则训练状态漂移 (回忆 77.4% → 修复后 96.6%)
- ★ 反例 (experiment14): margin 门控无判别力 — 正确回忆 margin med=0.09
  vs 错误 med=0.05 重叠严重; θ>0 回退 W_seq 烂输出 (θ=0.5 → 28.6% vs
  无门控 96.6%)。margin = min_j|raw_j| 不是可靠置信度

## 训练方式

### 离线训练

1. **W_h2o**: 随机稠密编码 → 8-bit 字符解码（奖赏调制 Hebbian）→ 72/72
2. **W_deep (层间)**: v12 渐进式深度训练 — 逐阶段加深 L1→L2→L3→L4，
   新层恒等初始化，每阶段解码 72/72
3. **W_ctx_to_first**: 工作记忆状态 → 首字符（奖赏调制 Hebbian，
   v12.3 确定性快照保证评估一致）
3b. **W_ctx_to_pos (位置记忆头)**: 工作记忆状态 → 回复第 k 字符（v13，
    复用 _coact_snapshots 快照，生成时修正非首字）
4. **W_seq**: 工作记忆状态 → 下一字符（奖赏调制 Hebbian，
   v12.3 逐对话快照 _seq_snapshots 保证评估一致）

### 已知限制 (v13 实测)

| 指标 | 结果 | 说明 |
|------|------|------|
| 字符解码 (W_h2o) | 72/72 (100%) | 完全学会 |
| 渐进式四层 (W_deep) | 各阶段 72/72 (100%) | 完全学会 |
| 首字符预测 (W_ctx_to_first) | 14 规模 100% | **14 样本过拟合**; 50-200 规模 10-18% < 多数基线 23-28% (experiment12) |
| 位置记忆头回忆 (W_ctx_to_pos) | 14 规模 96.6% | 逐位置 Hebbian 分类器; 快照一致后 77.4%→96.6% (experiment14); **v14 DG64 下 100%** |
| 位置记忆头回忆 (DG64 稀疏分离, v14) | 14/50/100 → 100%/35%/16% | DG top-k pattern separation 确证串扰为主因; 小库根除, 大库缓解有限 (experiment17) |
| 生成链路首字符 | 14/14 (100%) | 快照恢复后 (Step 4); 开放链路无快照仍漂移 (Step 5 泛化) |
| 生成链路字符级 (修正关) | 39.7% | W_seq 循环, 快照一致状态 |
| 生成链路字符级 (修正开) | **96.5%** | 位置记忆头修正 (θ=0 记忆优先); 完整匹配 1/14 |
| 序列预测 (W_seq) | ~5-22% | **结构性不可解** — 规则每 bit 独立决策 vs 8-bit 联合目标 (experiment11) |
| 异联想链 (W_trans) | 3-8% | bigram 平均混合, 远低于 34.1% 天花板 (experiment13) |
| 8 层隐藏层 | 61.0% 字符级 | 深层链路稀释判别性 (vs 4 层 79.2%); 无循环也退化 (experiment15) |
| 8 层 + 自回归循环 | **1/72 解码** | **彻底失败** — 双重损害: 输出判别性逐轮压缩 (汉明 125→85) + 训练目标不稳定 (experiment15/15b/15c) |

**v13.1 8 层 + 自回归循环失败记录** (experiment15):
- 用户方向: "隐藏层扩展到 8 层, 每次输入后自回归循环一次再传入输入"
- 已实现参数化 n_loops (默认 1, 向后兼容; num_layers 默认仍 4)
- 实测: L4 基线 79.2% → L8 无循环 61.0% → **L8+循环 18.4%** (解码 1/72)
- 根因 (底层机制, 假说检验):
  - experiment15b 证伪"V 饱和到全发放": 循环 4 次活跃率仅 0.44→0.52

  结构性限制 — 位级学习存在 (~74%), 但 8-bit 联合全对 = 位准确率乘积,
  天然 < 整模式查表 (多数一致基线)

**W_seq 决定性实验 — 规则容量结构性限制证实** (experiment11):
- 方法: 固定 RPE Hebbian + 二值阈值解码, 输入替换为理想化 one-hot 当前字符
- 结果: one-hot 22.7% << 信息论天花板 34.1% (多数一致精确匹配);
  随机稠密当前字符 15.6-20.5% (与 one-hot 同量级)
- 网络状态 (MemWork) 5.4% — 状态信息缺失是次瓶颈, 但即使状态完美
  (one-hot) 也远低于天花板 → **规则本身容量不足**
- 根因: RPE Hebbian 每 bit 独立决策 + 8-bit 联合目标 → "逐 bit 多数"
  ≠ "整模式多数" (Naive-Bayes 式独立决策 vs 联合最优) — 结构性限制
- 结论: 逐字符 next-char 预测在"纯二值 RPE Hebbian + 8-bit 独立解码"
  约束下结构性不可解 — **W_seq 方向关闭** (除非放宽学习规则约束);
  状态改造最多到 ~20% (规则上限), 收益有限且风险高 (可能破坏 14/14)

## 严格禁止的技术

以下技术**绝对不允许**出现在任何代码路径中：

| 禁止项 | 原因 |
|--------|------|
| 梯度下降 / SGD / Adam / 任何优化器 | 生物学中不存在 |
| 反向传播 / autograd / torch.autograd | 生物学中不存在 |
| 损失函数 / MSE / CrossEntropy | 神经元没有全局误差信号 |
| Transformer / Attention / Self-Attention | LLM 路线，非生物 |
| Tokenizer / Embedding / Vocab | 生物没有 token 化过程 |
| Softmax / Sigmoid 输出层 | 神经元发放是二值，不是概率 |
| 批量训练 / mini-batch / epoch 平均 | 生物每步独立学习 |
| 余弦相似度 / 向量检索 / KNN | 这是检索，不是思考 |
| 经验回放 / Replay Buffer | 生物没有显式回放缓冲区 |
| 权重共享 / 参数绑定 | 每个突触独立 |

**关于多层堆叠的说明 (v10)**: 本架构允许 **4 层前馈隐藏层**（L1→L4，层间无反馈、无 W_hh 循环、无时间步迭代），这是皮层分层处理（L2/3, L4, L5, L6）的生物映射。禁止超过 4 层的深堆叠。

## v3.8 — slot 角色路由组合泛化 (2026-08-22)

在纯 spiking LIF 框架 (core/lif_v36.py 已随本版本入库) 上解决组合泛化的
binding problem。核心交付模块 `slot_route_v38.py`, 复现与结果详见
`experiments/v38_slotroute/README.md`。

关键思想: 单一融合态的 superposition 物理性丢失"位置×内容"绑定
(融合态两两重叠 0.77)。解法 = **角色路由(位置) + 词级分离表征(内容) 解耦**,
六个专用读出头全 margin 斜坡 Hebbian 学习。

| P50 (96 拉丁方) | 10adj×10animal 训练96 | 96/96 | 4/4 |
| P51 (60 条验收) | 扩充 15×15=225, 训练60 | 60/60 | 5/6 |
