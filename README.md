## 项目目标

构建一个**纯粹的生物神经元计算系统**，目标是实现**类脑思考**而非大语言模型式的统计预测。

### 核心原则

- **不走 LLM 路线**：不使用 Transformer、Attention、Embedding、Tokenization 等大语言模型技术
- **不用求导**：任何形式的导数、偏导、梯度计算都不允许
- **不用梯度反向传播**：完全禁止反向传播算法、自动微分 (autograd)、梯度下降及其变体
- **不用损失函数**：不使用均方误差、交叉熵等任何形式的误差函数
- **不用批量优化**：每个样本独立学习，不累积梯度，不批量更新

### 生物学第一性原理

神经科学的已知事实决定架构设计，而非工程便利：

| 生物学事实 | 架构实现 |
|-----------|---------|
| 神经元膜电位是连续值 | V ∈ [0, 1] 膜电位积分 |
| 神经元发放是"全或无" | 二值输出 {0, 1} |
| 突触连接是稀疏的 | 选择性连接掩码 (~50% 稀疏) |
| 抑制性中间神经元实现 WTA | 侧抑制机制 |
| STDP 是局部的、奖赏调制的 | 奖赏调制 Hebbian 学习 |
| 工作记忆通过持续发放维持 | 0-1 分级状态累积 + 随机遗忘 |
| 神经元不会连接到所有其他神经元 | 选择性连接，非全连接 |
| 学习不需要标签，只需要结果好坏 | 二值奖赏信号 (+1/-1) |

## 架构概览

### 四层隐藏层 + 双记忆层结构 (v13)

```
输入层 (256 维)  ──→  L1 (256)  ──→  L2 (256)  ──→  L3 (256)  ──→  L4 (256)
                     │              │              │              │
                     └── 选择性连接掩码 (50% 稀疏)  层间权重 W_deep (v12 渐进式训练)
                     └── 侧抑制 (WTA) 每层内部
                                                                    │
                                        ┌───────────────────────────┤
                                        ▼                           ▼
                              工作记忆层 MemWork           关联记忆层 W_coact
                              (v12.2 now 模式:           (共发放追踪 + 回忆提取,
                               max(V累积, recall))         v12.3 确定性快照)
                                        │                           │
                                        └─────────────┬─────────────┘
                                                      ▼
                                  位置记忆头 W_ctx_to_pos[k] (v13, 修正非首字)
                                                      ▼
                                              输出解码 (W_ctx_to_first / W_seq / W_h2o)
```

- **L1 权重 (W_ih)**: 随机固定输入权重，永不训练
- **L2-L4 层间权重 (W_deep)**: **v12 渐进式深度训练** — 逐阶段加深 (输入→L1→输出 →
  输入→L1→L2→输出 → ... → L1..L4)，新层初始化为恒等映射 (纯中继)，保持已学表示不被破坏
- **工作记忆层 MemWork**: v12.2 now 模式 — `max(V 累积膜电位, recall)`，无跨字符累积；
  v12.4 recall 改为**分级回忆强度**（非二值化，判别性修复关键）
- **关联记忆层 W_coact**: 共发放追踪 + 回忆提取；v12.3 确定性快照保证训练/评估状态逐位一致

### 组件清单

| 组件 | 维度 | 说明 |
|------|------|------|
| W_ih | 256×256 | 随机固定输入权重 (L1)，带 50% 选择性连接掩码，永不训练 |
| W_deep | 3×256×256 | L1→L2→L3→L4 层间权重，奖赏调制 Hebbian 训练 |
| V / V_deep | 256×4 | 各层膜电位向量，每个神经元 ∈ [0, 1] |
| W_h2o | 8×256 | 解码权重，奖赏调制 Hebbian 训练 |
| W_ctx_to_first | 8×256 | 记忆状态→首字符，奖赏调制 Hebbian 训练 |
| W_ctx_to_pos[k] | 8×256 × 61 | **位置记忆头 (v13)**: 记忆状态→回复第 k 字符，生成时修正非首字 |
| W_seq | 8×256 | 记忆状态→下一字符，奖赏调制 Hebbian 训练 |
| W_coact | 256×256 | 关联记忆层，共发放追踪 + 回忆 |
| MemWork | 256 | 工作记忆层，0-1 分级上下文状态 |

## 核心机制

### 0-1 膜电位神经元

```
漏电:     V = V × (1 - leak)
积分:     V = clamp(V + sum(W_ih × input), 0, 1)
发放:     output = 1 if V > threshold else 0
重置:     V = V × (1 - reset_factor) if fired
侧抑制:   未发放神经元的 V 被抑制
```

### 纯二值奖赏调制 Hebbian 学习（唯一允许的学习规则）

```
Δw_ji = lr × dopamine_j × out_j × pre_activity_i

dopamine_j = +1 (该位正确), -1 (该位错误)
out_j      = 突触后神经元二值输出 {0, 1}
pre_i      = 突触前神经元二值活动 {0, 1}
```

**这是整个系统中唯一允许的权重更新方式。** 没有梯度、没有反向传播、没有自动微分、没有损失函数。

### 字符编码

```mermaid
flowchart LR
    A[字符 'H'] --> B[ASCII 码 72]
    B --> C[RandomState(72)]
    C --> D[256 维二值向量\n~50% 活跃]
    D --> E[+ input_bias=1.0]
    E --> F[输入信号 {1, 2}]
```

### 工作记忆层 (v12.2 now 模式 + v12.4 分级回忆)

```python
# 工作记忆 MemWork — "now 模式", 无跨字符累积 (v11 移除 forget_mask / OR 累积)
v_peak = V_deep[-1]              # 最深层累积膜电位 (V 跨字符持续累积, 不 reset)
recall = recall_from_memassoc(L4_out)  # 分级回忆强度 (W_coact 提取, v12.4)
MemWork = max(v_peak, recall)    # 逐元素最大, 不跨字符 OR 累积
```
**已验证的顺序约束** (experiment9 / diag_cmp3)：`update_coactivation` 必须先于
`recall`；`v_peak` 必须取累积 V (而非输出)；不逐字符 reset。任何顺序/来源变更
→ 状态判别性崩塌 (0-2/14 vs 9-11/14)。

**v12.4 关键修复 — 回忆由二值化改为分级** (diag_ctx_discrim):
- 原: `recall = (raw > 0.5).float()` — 阈值二值化丢失回忆强度信息，
  经 max 注入状态后判别性崩塌 (独立 W_ctx_to_first 5/14)
- 现: `recall = clamp(raw / (H/2), 0, 1)` — 先除期望最大共激活数再饱和钳位，
  保留分布形状 → 14/14
- ★ 反例: 直接 `clamp(raw, 0, 1)` 也失败 (4-5/14) — raw 量级常 > 1，
  直接钳位大量饱和，信息同样丢失

### 关联记忆层 (v10 + v12.3 快照)

```python
# 关联记忆 W_coact: 共发放追踪 (Fire together, wire together)
# 学习: 每个字符处理时累积共发放 (归一化到 [0,1])
# 回忆: recall = clamp(W_coact × L4_out / (H/2), 0, 1)   # 分级回忆强度 (v12.4)
# 注意: 这是突触矩阵线性回忆 (Hebbian 回忆)，不是余弦相似度/向量检索
#
# v12.3 确定性快照 — 连续累积是判别性来源, 但评估时必须重放训练时的状态:
#   收集: 每个对话编码前记录 W_coact.clone() → _coact_snapshots
#   评估: 恢复对应快照 + update_memory=True 重放 → 与训练状态逐位一致
#   W_seq: 同样方案 (train_sequence 逐对话记录 _seq_snapshots)
#   反例: 单一冻结 → 状态余弦 1.000 崩塌; 评估继续累积 → 状态漂移 (2/14)
```

### 层间渐进式深度训练 (v12)

```python
# W_deep (L1→L2→L3→L4): 逐阶段加深的课程式学习
# 阶段 depth=1..4:
#   1. 若 depth>1: 新中间层初始化为恒等映射 (scale=1.0, noise=0.0) — 纯中继
#   2. 训练 W_h2o (RPE 解码) + 李层 (仅当 mean_rpe>0: ΔW=lr×mean_rpe×outer(后,前))
# 恒等初始化保证: 新层加入前表示已正确, 无错误 → 无 RPE → 不更新 → 不被破坏
# 生物学依据: 皮层分层逐级成熟; 全局多巴胺奖赏门控 (只强化不惩罚)
```

### 循环生成 + 位置记忆头修正 (v13)

```mermaid
flowchart LR
    A[上下文状态 MemWork] --> B[W_ctx_to_first]
    B --> C[首字符]
    C --> D[编码→四层前向 L1→L4]
    D --> E[关联记忆更新/回忆 + MemWork 累积]
    E --> F[W_seq]
    F --> G[下一字符候选]
    G --> H{位置记忆头 W_ctx_to_pos[step]<br/>记忆优先覆盖 (θ=0)}
    H --> I[最终下一字符]
    I --> D
```

**位置记忆头 (v13)** — 对非首字结果进行修正:
- 训练: `train_pos_heads(dialogues)` — 对回复每个位置 k 训练独立 Hebbian
  分类器 W_ctx_to_pos[k] (上下文状态 → 第 k 字符, 与 W_ctx_to_first 同机制)
- 修正: 生成时每步用位置头对上下文状态 cf 回忆"回复第 step 字符"并直接
  覆盖 W_seq 候选 (记忆优先); 超出已训练位置回退 W_seq
- **快照一致性**: train_pos_heads 必须复用 `_coact_snapshots` 恢复状态再
  编码, 否则训练状态漂移 (回忆 77.4% → 修复后 96.6%)
- ★ 反例 (experiment14): margin 门控无判别力 — 正确回忆 margin med=0.09
  vs 错误 med=0.05 重叠严重; θ>0 回退 W_seq 烂输出 (θ=0.5 → 28.6% vs
  无门控 96.6%)。margin = min_j|raw_j| 不是可靠置信度

## 训练方式

### 离线训练

1. **W_h2o**: 随机稠密编码 → 8-bit 字符解码（奖赏调制 Hebbian）→ 72/72
2. **W_deep (层间)**: v12 渐进式深度训练 — 逐阶段加深 L1→L2→L3→L4，
   新层恒等初始化，每阶段解码 72/72
3. **W_ctx_to_first**: 工作记忆状态 → 首字符（奖赏调制 Hebbian，
   v12.3 确定性快照保证评估一致）
3b. **W_ctx_to_pos (位置记忆头)**: 工作记忆状态 → 回复第 k 字符（v13，
    复用 _coact_snapshots 快照，生成时修正非首字）
4. **W_seq**: 工作记忆状态 → 下一字符（奖赏调制 Hebbian，
   v12.3 逐对话快照 _seq_snapshots 保证评估一致）

### 已知限制 (v13 实测)

| 指标 | 结果 | 说明 |
|------|------|------|
| 字符解码 (W_h2o) | 72/72 (100%) | 完全学会 |
| 渐进式四层 (W_deep) | 各阶段 72/72 (100%) | 完全学会 |
| 首字符预测 (W_ctx_to_first) | 14 规模 100% | **14 样本过拟合**; 50-200 规模 10-18% < 多数基线 23-28% (experiment12) |
| 位置记忆头回忆 (W_ctx_to_pos) | 14 规模 96.6% | 逐位置 Hebbian 分类器; 快照一致后 77.4%→96.6% (experiment14); **v14 DG64 下 100%** |
| 位置记忆头回忆 (DG64 稀疏分离, v14) | 14/50/100 → 100%/35%/16% | DG top-k pattern separation 确证串扰为主因; 小库根除, 大库缓解有限 (experiment17) |
| 生成链路首字符 | 14/14 (100%) | 快照恢复后 (Step 4); 开放链路无快照仍漂移 (Step 5 泛化) |
| 生成链路字符级 (修正关) | 39.7% | W_seq 循环, 快照一致状态 |
| 生成链路字符级 (修正开) | **96.5%** | 位置记忆头修正 (θ=0 记忆优先); 完整匹配 1/14 |
| 序列预测 (W_seq) | ~5-22% | **结构性不可解** — 规则每 bit 独立决策 vs 8-bit 联合目标 (experiment11) |
| 异联想链 (W_trans) | 3-8% | bigram 平均混合, 远低于 34.1% 天花板 (experiment13) |
| 8 层隐藏层 | 61.0% 字符级 | 深层链路稀释判别性 (vs 4 层 79.2%); 无循环也退化 (experiment15) |
| 8 层 + 自回归循环 | **1/72 解码** | **彻底失败** — 双重损害: 输出判别性逐轮压缩 (汉明 125→85) + 训练目标不稳定 (experiment15/15b/15c) |

**v13.1 8 层 + 自回归循环失败记录** (experiment15):
- 用户方向: "隐藏层扩展到 8 层, 每次输入后自回归循环一次再传入输入"
- 已实现参数化 n_loops (默认 1, 向后兼容; num_layers 默认仍 4)
- 实测: L4 基线 79.2% → L8 无循环 61.0% → **L8+循环 18.4%** (解码 1/72)
- 根因 (底层机制, 假说检验):
  - experiment15b 证伪"V 饱和到全发放": 循环 4 次活跃率仅 0.44→0.52
  - experiment15c 部分证实"信息趋同": 两随机输入汉明距离 125→85
    (~30% 压缩, 未坍缩到同一吸引子)
  - 完整机制: (a) 循环逐轮压缩输出判别性; (b) 第二轮输入 = 第一轮
    未训练好的输出 → RPE Hebbian 训练目标移动无法收敛。0-1 膜电位
    瞬时前向系统不适合自回归循环 (与"禁止时间步迭代"约束一致)

**v13 修正收益与泛化权衡** (experiment14 / test Step 4-5):
- 对训练对话 (记忆场景, 快照恢复): 修正开字符级 39.7% → **96.5%**,
  完整匹配 0/14 → 1/14 (oracle 长度下 6/14); 样例仅少量错字
  ("I'm sorpy..." / "the chicken aross the road")
- ★ 泛化权衡: 记忆优先 (θ=0) 下未见输入产生**记忆幻觉** — 位置头对
  任意输入都回忆 (margin > 0 恒真), 状态不匹配 → 乱码长串。margin
  门控 (θ=0.5) 可抑制幻觉但训练对话修正收益也崩 (28.6%)。margin 无
  判别力 → 无法用单一阈值两全。在线学习 (train_on_dialogue) 不更新
  位置头, 新对话不被修正 (已知限制)

**v14 文献驱动升级 — 三因子资格迹(A) × DG 稀疏分离(B)** (experiment17):
- 背景: 用户指令"上网调研学习, 不再盲目试错"。文献归因 experiment16
  记忆库扩容崩溃 (14→50 对话 69.8%→20.9%) 为"稠密 Hebbian 关联记忆串扰
  (crosstalk)" + "即时 RPE 权重抖动"。理论依据: CLS (Schapiro 2017) /
  HiCL 2025 (DG top-k pattern separation) / Gerstner & Lehmann 2018
  (三因子资格迹)。
- 新参数 (RecurrentLIFSimulator, 默认 False 向后兼容):
  - `use_dg_separation` + `dg_k`: DG 稀疏分离 — 记忆头输入 top-k 二值
    稀疏化 (`_dg_separate` → `_mem_feature` 统一入口, 训练/推理一致)
  - `use_eligibility_trace` + `eligibility_lambda`: 三因子资格迹
    (e_ji ← λe_ji + pre×post; Δw = lr × M_j × e_ji)
- ★ H1 (资格迹) **证伪**: 所有规模下破坏性 (4-6% vs 基线 70%)。根因:
  位置头无时间链, 迹把跨样本共激活历史混入每次更新 → 串扰放大器;
  三因子资格迹的价值在"延迟奖赏的时间信用分配", 无时间链场景不适用
- ★ H2 (稀疏分离) **部分证实**: k=64 (25% 稀疏) 是甜点 —
  - 库14: 位置头 70%→**100%**, 端到端字符级 72%→**100%** (完整句 14/14)
  - 库50: 20%→**35%** (抗住一半), 库100: 14%→**16%** (缓解有限)
  - k=32 过稀疏丢判别信息 (库50 仅 16%); 稀疏度是容量关键参数
- 结论: DG 稀疏分离确证串扰是扩容崩溃主因之一, 小库近乎根除;
  剩余衰减 (50/100) 指向**上下文编码层判别性**为下一瓶颈 (50+ 对话
  状态两两余弦趋近 1, W_ih 固定随机编码无法区分)
- 推荐配置: `use_dg_separation=True, dg_k=64` (保持资格迹关闭)

**v14 P1 事件联合记忆 — 同时解"无限上下文"与"时间序列"** (experiment18):
- 用户指令: "还有什么办法能同时满足无限上下文和时间序列"

- 文献: Horner 2015 (整体情景回忆) / Kanerva SDM (稀疏高维容量线性扩展) /

  - v2: 输入改字符绑定 → 位置间串扰 (长回复 34 字符下反排列残留

  - v3: 块绑定 (每位置独占维度块) → 位置串扰归零 → 库14 99.0%

  | 库 | P1 (D8192) | 基线 | 提升 |
  |----|-----------|------|------|
  | 14 | 99.0% | 100% | 持平 |

  | 100 | 48.1% | 16% | +32.1pp |

- 结论: 事件绑定 + 整体补全确证"整体存储"是同时解两问题的正路,
  大库容量显著超越所有逐字符方案; 剩余衰减 = **事件间串扰**
  (200 事件 × 输入码重叠), 缓解方向: 更高维度 / 更强分离 (现代 Hopfield
  非线性项) / 长度归一化。

**v14.2 自回归事件记忆 v2 — 上下文消歧修复** (experiment20):

  E2 同一列叠加多对话的下一步 → 共享前缀投票污染; 库内 12.1%

  消歧标签, 前缀作进度指示; 输入/前缀分占正交块 (dim=12288, 块 192)。
- 结果 (库内前14 / 库外10, LIF DG64 底座同 sim 对照):
  | 场景 | A 位置头DG64 | C 自回归 v2 | v1 对比 |

**v14.3 SDM 非叠加存储突破 + 动态容量四败** (experiment25-34):

- 系列根因判定 (experiment25/28): E2 线性叠加容量硬顶 = 存储表示问题,
  不是训练量/规模问题 — 1×==5× 重复印刻无效; AR 本质是 2-gram 级
  转移统计 (3-gram 80.3% > AR 73.1%; 仅前缀 76.4% > 完整 73.1% —
  teacher 场景输入是噪声, "系统性错误" = 转移统计多数派 vs 目标对话)。
- ★ SDM 非叠加存储 (experiment29): 固定随机稀疏地址 (4096 地址,
  每地址 24 位) + top-k (k=64, 1.6% 激活) 就近 Hebbian 写入/读出:
  | 库 | SDM teacher/free | E2 AR 对照 |
  |----|------------------|-----------|
  | 50 | **93.2% / 91.6%** | 73.1% |
  | 100 | **79.0% / 62.1%** | 62.1% |
  结论: "信息一直都在, 是 E2 叠加把它抹掉了"。参数甜点: 负载≈18
  (k×事件/地址), 地址 24 位; 8192 vs 4096 于库400 +13.6pp (容量需求真实)。
- ❌ 动态容量四败 (experiment30-34), 根因统一 = **有偏投影破坏均匀聚桶**:

  - v3 活性偏置+成熟期 → 扩增停滞 (58.6%)
  - v4 负载目标批量 → 活性地址过拟合单对话 (24.6%)

**v12.4 判别性修复** (diag_ctx_discrim): 状态信号 `state = max(v_peak, recall)`
中, 二值化回忆 `(raw > 0.5)` 丢失强度信息 → 判别性崩塌 (独立 W 5/14);
改为分级回忆 `clamp(raw / (H/2), 0, 1)` → 14/14。v_peak 分级本就 14/14,
recall 经 max 注入二值低判别性模式是瓶颈根因。

**规模泛化验证** (experiment12): 14/14 (100%) 是过拟合 (memorization):
- N=50/100/200 时准确率 18%/13%/10%, 均低于多数类基线 28%/26%/23%
- 状态两两余弦随规模升至 0.994-0.995 (判别性崩塌)
- ★ 与 experiment11 交叉印证: 系统级"逐 bit 独立决策 vs 8-bit 联合目标"
  结构性限制 — 位级学习存在 (~74%), 但 8-bit 联合全对 = 位准确率乘积,
  天然 < 整模式查表 (多数一致基线)

**W_seq 决定性实验 — 规则容量结构性限制证实** (experiment11):
- 方法: 固定 RPE Hebbian + 二值阈值解码, 输入替换为理想化 one-hot 当前字符
- 结果: one-hot 22.7% << 信息论天花板 34.1% (多数一致精确匹配);
  随机稠密当前字符 15.6-20.5% (与 one-hot 同量级)
- 网络状态 (MemWork) 5.4% — 状态信息缺失是次瓶颈, 但即使状态完美
  (one-hot) 也远低于天花板 → **规则本身容量不足**
- 根因: RPE Hebbian 每 bit 独立决策 + 8-bit 联合目标 → "逐 bit 多数"
  ≠ "整模式多数" (Naive-Bayes 式独立决策 vs 联合最优) — 结构性限制
- 结论: 逐字符 next-char 预测在"纯二值 RPE Hebbian + 8-bit 独立解码"
  约束下结构性不可解 — **W_seq 方向关闭** (除非放宽学习规则约束);
  状态改造最多到 ~20% (规则上限), 收益有限且风险高 (可能破坏 14/14)

## 严格禁止的技术

以下技术**绝对不允许**出现在任何代码路径中：

| 禁止项 | 原因 |
|--------|------|
| 梯度下降 / SGD / Adam / 任何优化器 | 生物学中不存在 |
| 反向传播 / autograd / torch.autograd | 生物学中不存在 |
| 损失函数 / MSE / CrossEntropy | 神经元没有全局误差信号 |
| Transformer / Attention / Self-Attention | LLM 路线，非生物 |
| Tokenizer / Embedding / Vocab | 生物没有 token 化过程 |
| Softmax / Sigmoid 输出层 | 神经元发放是二值，不是概率 |
| 批量训练 / mini-batch / epoch 平均 | 生物每步独立学习 |
| 余弦相似度 / 向量检索 / KNN | 这是检索，不是思考 |
| 经验回放 / Replay Buffer | 生物没有显式回放缓冲区 |
| 权重共享 / 参数绑定 | 每个突触独立 |

**关于多层堆叠的说明 (v10)**: 本架构允许 **4 层前馈隐藏层**（L1→L4，层间无反馈、无 W_hh 循环、无时间步迭代），这是皮层分层处理（L2/3, L4, L5, L6）的生物映射。禁止超过 4 层的深堆叠。
